# Калькулятор сайзинга платформы Штурвал

Статический сайт, который считает размер узлов кластеров платформы Штурвал: control-plane, infra, ingress и workers, а также свои группы узлов. Учитывает выбранные сервисы, тип хранилища и прикладные нагрузки.

Сайт: https://shturval-tech.github.io/sizing/

В ветке `main` только этот README и лицензия, опубликованный сайт лежит в ветке `gh-pages`. Исходный код ведётся отдельно, поэтому изменения сайта напрямую в этот репозиторий не вливаются.

## Как сообщить о проблеме или предложить идею

Откройте [issue](https://github.com/shturval-tech/sizing/issues/new). Чтобы мы быстро разобрались, укажите:

- версию релиза платформы, выбранную в шапке сайта;
- режим площадки: «Новая площадка» или «Клиентские в существующее управление»;
- что вы настроили: число узлов по группам, провайдер, тип CSI, нужные сервисы, нагрузки (достаточно описания или скриншота без внутренних данных);
- что получилось и что вы ожидали;
- браузер и его версию, если проблема в отображении.

Не прикладывайте в issue адреса внутренних систем, токены и содержимое `kubeconfig`. Для расчёта они не нужны.

## Как предложить изменение (pull request)

1. Сделайте fork репозитория.
2. Создайте ветку от `main` и внесите изменение.
3. Откройте pull request в `main` и опишите, что и зачем меняется. Для правки расчёта приложите пример входных данных и ожидаемый результат.

Мы рассмотрим pull request и перенесём принятые изменения в основную разработку, после чего опубликуем новую версию сайта. Из-за этого pull request может быть закрыт без merge, а изменение войдёт в одну из следующих публикаций. Изменения опубликованных файлов в `gh-pages` принимаются так же, но перезапишутся следующей публикацией. Мелкие правки, например опечатки в текстах, удобнее оформить как issue.
